## 🎯 Number Guessing Game

A simple command-line game built in Python where the player tries to guess a randomly generated number between 1 and 100.

## 📌 Description

This project demonstrates basic Python concepts like loops, conditionals, input validation, and user interaction. The game provides hints after each guess to guide the player toward the correct number.

## ⚙️ Features
* Random number generation
* Input validation (only digits allowed)
* Hint system (too high / too low)
* “Very close” feedback when near the answer
* Tracks number of attempts
* Option to exit the game
## ▶️ Getting Started
Requirements
* Python 3.x
Run the program
python guessing_game.py
## 🧠 How It Works
1.The program generates a random number between 1 and 100

2.The user enters a guess

3.The program gives feedback:
* Too small → guess higher
* Too big → guess lower
* Very close → within range

4.The game continues until:
* The correct number is guessed
* Or the user types exit
